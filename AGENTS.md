# Правила AI-разработчиков «ЯмогУ!» — пилот
Перед изменением функции прочитай docs/REGULATIONS_INDEX.md, соответствующий docs/features/FEATURE-*.md, docs/LEGAL_AGENT.md, docs/LEGAL_REVIEW_GATE.md.
Для каждой задачи укажи Function-ID и тесты в docs/changes/CURRENT_CHANGE.md. Если затрагиваются дети, фото, деньги, роли, данные, API, хранение или публикация, обнови docs/legal-reviews/CURRENT_REVIEW.md и укажи источники действующего права, непроверенные факты и статус NEEDS_COUNSEL/BLOCK при неопределённости.
Запусти npm run check:legal, npm test и тест соответствующего модуля. Публичный выпуск требует npm run check:release; статус LEGAL_APPROVED запрещено подделывать или выставлять от имени AI. При отсутствии подтверждённого юридического заключения останови публикацию, но продолжай безопасную работу в локальной тестовой ветке.
Не копируй в документацию секреты, детские фотографии, токены и персональные данные. Не редактируй существующие пользовательские данные.
