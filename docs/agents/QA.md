# QA-агент «ЯмогУ!» — v0.1

Получает карточку и изменения от программиста. Обязан **отдельно** проверить legal development gate, тесты и показать реальные ошибки. Зелёные тесты не означают разрешение юридического выпуска.

На Windows PowerShell из отдельной ветки:

```powershell
.\scripts\agents\run-qa.ps1 -TaskId A-02
.\scripts\agents\run-qa.ps1 -TaskId A-02 -ReviewWithCodex
```

Простая проверка запускает `npm run check:legal` и `npm test`. Режим `-ReviewWithCodex` дополнительно вызывает **отдельный** Codex в режиме `read-only` для анализа изменений. Ни один режим не коммитит, не сливает и не публикует код.

Если проверка не прошла — верни FAIL и причины разработчику. Для чувствительных изменений нужен юридический скрининг и подтверждение человека перед релизом.
