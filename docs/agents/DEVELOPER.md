# Агент-программист (Codex) — v0.2

Назначение: выполнять **одну явно записанную задачу** из `docs/agents/tasks/` в отдельной ветке и передавать изменения тестировщику. Это управляемый запуск, а не круглосуточный автономный агент.

## Команды на Windows (PowerShell)

Из папки `yamogu-web` в **изолированном worktree / отдельной ветке**:

```powershell
.\scripts\agents\run-developer.ps1 -TaskId A-02
.\scripts\agents\run-developer.ps1 -TaskId A-02 -Run -ReadOnly
# Запись кода только для подготовленной задачи и чистой ветки:
.\scripts\agents\run-developer.ps1 -TaskId F-005 -Run
```

Последний пример возможен **только после отдельной карточки F-005** с ограничениями, проверками и допусками. Без файла карточки запуск блокируется. По умолчанию — безопасная проверка без вызова Codex.

## Контроль

1. Координатор создаёт карточку по `TASK_TEMPLATE.md`, назначает роль и критерии приёмки.
2. Разработчик читает `AGENTS.md` и регламенты функции, работает вне `main`; грязная ветка блокирует режим записи.
3. Codex вызывается через CLI с sandbox `workspace-write` или `read-only`; не получает команд на релиз, слияние, push или назначение юридического статуса.
4. После записи запускаются `npm run check:legal` и `npm test`. Любая ошибка останавливает передачу на приёмку.
5. QA отдельно смотрит diff и воспроизводит тесты. Коммит, PR, релиз и юридическое согласование не выполняются самим раннером.

**Ограничения:** процесс не является постоянным автономным сервисом; локальная система и GitHub могут требовать отдельной авторизации Codex. Отчёт Codex пишется во временную папку Windows, не в Git. Реальные данные детей не используются.
