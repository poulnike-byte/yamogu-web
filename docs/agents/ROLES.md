# Роли «ЯмогУ!»
Роли пока оформлены как инструкции, а не независимо работающие процессы.

| Роль | Результат | Кому передать |
|---|---|---|
| Координатор | план, приоритет, критерии приёмки, отчёт | владелец проекта |
| Разработчик | код в отдельной ветке, diff, тесты | QA |
| UX-дизайнер | макет, сценарии 6–9/10–12, состояния, доступность | разработчик |
| QA-тестировщик | pass/fail, регрессии, шаги воспроизведения | координатор |
| Безопасность | угрозы, доступы, хранение и удаление данных детей | QA и юридический скрининг |
| Юридический скрининг | нормы с источником, риск, BLOCK/NEEDS_COUNSEL/CONDITIONAL/NO_ISSUES_FOUND | юрист РФ и ответственный |
| Аналитик | только подтверждённые метрики, отклонения от плана | координатор |

Каждая роль соблюдает `AGENTS.md` и регламенты. Критические риски останавливают публикацию, но не безопасные тесты.
