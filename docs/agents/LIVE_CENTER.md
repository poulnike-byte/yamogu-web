# Live-центр «ЯмогУ!» — локальный пилот

## Как включить
На ноутбуке запускайте `scripts/agents/start-live-center.cmd`, затем откройте `http://127.0.0.1:8765`. Для удобства можно запустить ярлык на рабочем столе `Yamogu_LIVE.cmd` (если он создан).

Сервер на Node.js слушает **только** `127.0.0.1`; интернет-страница GitHub и локальный HTML-файл не могут показывать живые процессы. Если закрыть окно сервера или выключить ноутбук, Live станет недоступным. Автозапуск в систему не добавлен.

## Как регистрируется работа
Только команды, вызванные через `monitor-run.ps1`, отражаются в Live. Из отдельной ветки/worktree в PowerShell:

```powershell
.\scripts\agents\monitor-run.ps1 -Role qa -TaskId A-04
.\scripts\agents\monitor-run.ps1 -Role developer -TaskId A-02
```

Программист запускает Codex **только для чтения**; QA выполняет `npm run check:legal` и `npm test`. Запуски без утверждённой карточки, в `main` и публикации не разрешены. Скрипты не делают merge, deploy и не оформляют LEGAL_APPROVED.

Временный журнал: `%TEMP%\yamogu-agent-monitor\events.jsonl`. Он содержит только роль, ID задачи, случайный идентификатор запуска, PID, время и конечный результат. Детские данные, фото, токены и логи команд в журнал не копируются.

Интерфейс обновляется каждые 3 секунды. Live «Работает сейчас» проверяет наличие PID процесса, а не текстовое обещание агента. Внезапно прерванный процесс отмечается как «Прервано»; если связь с сервером потеряна, показывается «Монитор недоступен», а не фиктивный зелёный статус.

Полосы диаграммы отражают **количество успешно завершённых запусков**, а не процент завершённости разработки. Роль без записанных запусков отображается как «Не запускался».
