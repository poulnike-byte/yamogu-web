# Юридический контроль перед выпуском
31.10.2026 · Статус: проект процесса.

Каждое изменение проходит AI-скрининг. Изменения по персональным данным детей, фотографиям, платежам, рекламе, сторонним сервисам и трансграничным данным требуют письменного заключения компетентного юриста РФ и решения ответственного за релиз.

## Чек-лист
- [ ] Обновлён регламент изменённой функции и версия.
- [ ] Составлены карта данных, сроки хранения, схема удаления и бэкапов.
- [ ] Проверены страна ЦОД, доступы, подрядчики и локализация.
- [ ] Есть законные основания обработки, политика и требуемые согласия.
- [ ] Проверены действующие нормы РФ, указан источник и дата.
- [ ] Пройдены автоматические и ручные тесты; описан откат.
- [ ] Есть AI-отчёт, а для критичного изменения — заключение юриста РФ.
- [ ] Ответственный разрешил выпуск.

NO LEGAL APPROVAL = NO PUBLIC RELEASE для изменений, затрагивающих фото и данные детей.
