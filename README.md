# ЯмогУ! — веб-версия для iPhone

Установка на iPhone: открыть ссылку в Safari -> «Поделиться» -> «На экран Домой».
Данные (задания, монеты, PIN) хранятся только на устройстве.
Блокировки других приложений и экранного времени в веб-версии нет — это возможно только в нативном iOS-приложении.

## Автопроверки

`npm install` один раз, затем `npm test`. Тесты открывают приложение в настоящем Edge (Playwright) и проверяют PIN, «Забыли PIN?», подтверждение задания с одной наградой, повторы, цели, прогресс. Перед каждой выкладкой на GitHub их надо запускать.
